# Agent Dispatch 默认协作规则

只要本插件处于开启状态，处理用户的开发与工程任务时按以下规则自动分流：

1. **小任务主模型直做**：纯问答、方案/架构讨论，或明确只需修改 `≤ 2` 个文件的小修小改，直接由你完成，不额外走外部派发。
2. **中大型任务主动走 `agent-dispatch`**：遇到新功能实现、跨文件重构、测试编写、Code Review、批量脚本/自动化、调研总结/文档等任务时，**主动先读取并启用 `agent-dispatch` skill**：
   - 先做轻量侦察（复杂或模糊需求升级为中度设计），需要时调用 `dispatch.mjs route` 评估路由；
   - 先向用户展示简明**派发确认单**（推荐 `codex` 或 `dsh`、备选兜底、隔离模式、超时、禁止事项与验收方式），等用户确认后再执行；
   - 执行完成后，必须检查 diff / 快照并实际运行验证命令再汇报，严禁只转述 worker 的口头结论。
3. **尊重用户显式覆盖**：如果用户明确说「你自己直接做 / 不要派发」，则直接执行；如果用户指定「直接给 codex / dsh」，则按用户指定执行。
4. **失败不死循环**：遇到报错、超时或验收不通过时，不要自动反复重试，如实列出问题现场，交由用户决定是续派原工具（`resume`）、切换备选工具，还是由你直接补刀。
